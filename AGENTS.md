# CHEM 1A teaching repository

This repository supports university CHEM 1A interactive teaching experiences. The current design target is `experiences/w01_spectroscopy`.

- Read repository and experience design sources before changing learner-facing pedagogy.
- Do not silently redesign pedagogy during technical work.
- Keep stable scientific/data machinery separate from changing experience-specific pedagogy where practical.
- Mature Data Science Streamlit interaction, accessibility, voice, and facilitator-support patterns may be reused where appropriate, but this is not a school or Data to Discovery experience.
- Preserve scientific provenance. Distinguish measured, reference, calculated, simulated, and illustrative data.
- Do not invent future CHEM 1A experiences.
- Keep changes bounded and verify in proportion to their risk.
- Learner-facing changes require rendered inspection, not tests alone.
- Verify GitHub and deployment state rather than assuming it.
